# AVR-ассемблер

[English version](assembly.md)

Эти приёмы полезны после просмотра связанного кода. Если AVR-GCC уже выдаёт ту же последовательность, предпочтите исходник на C. Проверьте набор инструкций и время исполнения именно для своего ядра.

## 1. Используйте результат инструкции и её флаги

`LSR` переводит 8-битное количество байтов в количество слов. Инструкция выставляет C для нечётного исходного числа и Z для нулевого результата, поэтому эти флаги можно использовать для проверки чётности и длины. Если счётчик гарантированно доходит до нуля после `SBIW`, его значение можно перенести в другую пару регистров через `MOVW`. Сохраняйте флаг от момента установки до чтения.

## 2. Сцепляйте сравнения через CPC

Для беззнакового 16-битного сравнения сравните младший байт первым. `CPC` использует перенос от `CP` и сохраняет Z установленным лишь при равенстве уже сравненных частей и текущего байта.

```asm
; a = r25:r24, b = r23:r22
cp   r24, r22
cpc  r25, r23
breq equal
; здесь BRLO может проверить a < b, пока C не испорчен
```

Замерьте оба случая: равенство и несовпадение. Цепочка может увеличить время при раннем несовпадении. В приёмнике с фиксированными окнами выборки после изменения пути сравнения проверьте время от начала пакета. [Две реализации проверки равенства](../examples/README_ru.md)

## 3. Переиспользуйте указатель и держите состояние в регистрах

Читайте последовательные данные через `LD Rd, X+` или `LPM Rd, Z+` на ядрах, где доступны эти формы. Держите аккумулятор MAC в регистрах и переносите оба байта через `MOVW` между парами с чётными номерами младших регистров. Для поля со смещением 20 команда `STD Z+20` может быть короче `STS`, если Z уже указывает на структуру на всех путях до записи. Если базу нужно отдельно загружать, пересчитайте размер и задержку. `STD` со смещением работает с Y или Z и имеет ограниченный диапазон смещений.

## 4. Сокращайте ветвления, учитывая все пути

Поставьте тело простого случая рядом с условием и поменяйте направление ветки, чтобы убрать лишний переход. В циклах можно использовать обратный отсчёт с `DEC/BRNE`. Для диапазона 0…255 отдельно обработайте ноль, иначе цикл выполнит 256 итераций. Расстояние до цели перехода, взятые ветки и размер пропускаемой инструкции могут изменить выигрыш.

## 5. Обращайтесь к битам прямо лишь при подходящем регистре

На классических AVR `SBI/CBI/SBIC/SBIS` обращаются к нижним 32 адресам **пространства I/O**. Используйте их, если адрес и поведение регистра это допускают. Перед заменой записи маски на операцию чтения, изменения и записи для регистра с флагами write-one-to-clear сверяйтесь с даташитом. Проверьте воздействие инструкции на соседние флаги.

## 6. Сохраняйте контракт ABI и прерываний

На классическом ABI AVR-GCC `MUL` пишет в `r1:r0`; перед возвратом или вызовом C восстановите ноль в r1. Прерывание может прийти в середине частного ASM, когда r1 ненулевой. Обычный ISR компилятора при использовании нулевого регистра сохраняет, обнуляет и восстанавливает его; ручной ISR должен сохранять прерванное состояние. При вызове из C также сохраняйте изменённые callee-saved регистры. Для inline ASM опишите раннюю перезапись выходов и эффекты на память в ограничениях и clobber-списке. У AVR Reduced Core другой ABI.

Между умножениями внутри процедуры можно убрать лишнюю очистку r1, если ни одна промежуточная инструкция не требует, чтобы он был нулём. Восстановите ноль перед следующим таким использованием и на границе с C. Проверьте прерывания в точках с ненулевым r1 и убедитесь, что ISR восстанавливает прерванное значение.
