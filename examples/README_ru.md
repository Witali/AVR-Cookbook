# Сравнения на AVR

[English version](README.md)

Запустите из корня `python3 examples/measure.py`. В Windows с инструментами AVR в PATH используйте `py -3 examples/measure.py`. Скрипт использует `avr-gcc`, `avr-size` и `avr-objdump`, складывает секции типовой компоновки ATmega328P и ATtiny85 и сохраняет ELF, карты и листинги. Обращения к регистрам I/O дают компилятору наблюдаемые операции. Сравнения выполняются на хосте.

| Пара | Что проверить в листинге |
| --- | --- |
| `table-ram` → `table-flash` | Индекс выбирается во время выполнения. Вариант Flash читает через `LPM`; таблица больше не занимает SRAM. |
| `channels-runtime` → `channels-mono` | У mono исчезают проверка числа каналов и запись в OCR1AL. Поведение при одном канале одинаково, возможности образа различаются. |
| `compare-split` → `compare-chain` | Два сравнения и одна развилка вместо двух. Ветвление при несовпадении младшего байта может стать медленнее, хотя функция меньше. |
| `blend-two-products` → `blend-one-product` | Интерполяция с одним умножением сохраняет округление вниз для входов в диапазоне −16 000…16 000. [Код на C](blend.c) |
| `stride-multiply` → `stride-table` | Для восьми записей по 23 байта на ATtiny85 таблица из восьми байтов Flash заменяет умножение индекса. Во второй сборке исчезает `__mulhi3`. [Код на C](stride.c) |
| `fifo-wrap-byte` → `fifo-wrap-block` | При выровненной записи блоков по четыре байта в кольцо на 20 байт указатель продвигается внутри блока, а переход через границу проверяется один раз. [Код на C](fifo-block.c) |
| `select-branch` → `select-skip` | Одна инструкция `LDI` условно пропускается, если селектор гарантированно равен 0 или 1. [Код на ассемблере](select-constant.S) |

Проверка равенства принимает оба 16-битных операнда в регистрах по ABI AVR-GCC. Для младшего байта, который отличается, исполнение до RET включительно занимает 8 тактов в раздельном варианте и 9 в цепочке; для совпавшего младшего байта ветка либо равенства, либо несовпадения старшего байта экономит такт. CALL, вход в main и доступ к RAM в этот подсчёт не входят.

Контрольная сборка использует AVR-GCC 7.3.0, `-Os`, удаление неиспользуемых секций и штатный стартовый код каждого устройства.

| Сравнение | MCU | Flash, Б | Статическая SRAM, Б |
| --- | --- | ---: | ---: |
| Таблица RAM → Flash | ATmega328P | 204 → 182 | 32 → 0 |
| Динамический режим → mono | ATmega328P | 178 → 140 | 2 → 0 |
| Два отдельных сравнения → CP/CPC | ATmega328P | 190 → 188 | 5 → 5 |
| Интерполяция с двумя умножениями → одно | ATmega328P | 324 → 294 | 6 → 6 |
| Умножение на шаг записи → таблица смещений во Flash | ATtiny85 | 128 → 102 | 185 → 185 |
| Проверка границы FIFO на каждом байте → раз на четыре байта | ATmega328P | 186 → 182 | 20 → 20 |
| Ветвление по булеву значению → пропуск одной инструкции | ATmega328P | 156 → 154 | 0 → 0 |

Это размеры полных тестовых ELF по загружаемым секциям, включая стартовый код. Первые две пары также меняют обязанности инициализации `.data`; дельта Flash не равна размеру таблицы или одной ветки.

На ATmega328P функция `select_constant` занимает 7 → 6 тактов при любом из двух значений селектора, с RET и без CALL. Запись блока в FIFO занимает 68 → 42 такта без перехода через конец кольца и 68 → 44 с переходом. Для FIFO отсчёт идёт от чтения `PINB` до следующего чтения. Такты посчитаны по связанному листингу. Одновременного чтения из FIFO в тесте нет.

## Проверка самостоятельных примеров на C

Примеры показывают скалярное произведение знаковых байтов, дробный период таймера и проверку непустого диапазона Flash с исключённой верхней границей. Проверяются пустой вход скалярного произведения, знаковые крайние значения, полный цикл дробного периода и диапазон, который при сложении переполнил бы тип адреса. [Код примеров](recipes.h) · [Проверки границ](check-recipes.c)

Из корня справочника соберите и запустите проверки с компилятором C в оболочке POSIX.

```sh
mkdir -p build
cc -std=c99 -Wall -Wextra -Werror examples/check-recipes.c -o build/check-recipes
./build/check-recipes
```

Оба варианта новых сравнений на C также можно проверить на хосте. Проверки охватывают границы знакового диапазона и выборку для интерполяции, все входные байты для выбора записи и все допустимые позиции FIFO с каждым входным байтом.

```sh
for source in blend stride fifo-block; do
    for variant in 0 1; do
        cc -std=c99 -Wall -Wextra -Werror -DVARIANT="$variant" \
            "examples/$source.c" -o "build/$source-$variant"
        "./build/$source-$variant"
    done
done
```
