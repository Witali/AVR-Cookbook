# AVR-Cookbook

[English version](README.md)

Практические оптимизации для классических 8-битных AVR. В каждом рецепте указано, когда применять приём, какие у него издержки и как проверить результат на своём контроллере.

| Если ограничивает… | Начните с… |
| --- | --- |
| Неясно, что занимает память и время | [Методика замеров](docs/measurement_ru.md): ELF, map, листинг, стек и худший путь |
| SRAM, Flash или ресурс EEPROM | [Память и конфигурация](docs/memory_ru.md): таблицы во Flash, специализация сборки, кольцевой журнал |
| Размер или такты нескольких инструкций | [AVR-ассемблер](docs/assembly_ru.md): флаги, регистры, указатели, ветвления и ABI |
| Задержка IRQ и опустошение FIFO | [Прерывания и потоки](docs/realtime_ru.md): таймеры, FIFO, предзагрузка и пределы задержки |
| DSP не укладывается в бюджет | [Целочисленная арифметика](docs/arithmetic_ru.md): узкие диапазоны, MAC, общие произведения и вынос вычислений на ПК |
| Bootloader не помещается | [Загрузчики и протоколы](docs/bootloaders_ru.md): общий код, размещение, контракт входа и тесты гонок |

Регистры и параметры инструментов описаны в официальных справочниках. Указатель DSP группирует приёмы по арифметике, фильтрам, буферам и воспроизведению. [Справочники AVR](docs/sources_ru.md) · [Указатель DSP](docs/dsp-index_ru.md)

Для семи сравнений на ATmega328P и ATtiny85 установите Python 3.10+, AVR-GCC, AVR-LibC и AVR binutils, затем запустите скрипт замеров.

```sh
python3 examples/measure.py
```

Скрипт собирает обе стороны каждого сравнения и оставляет ELF, map и дизассемблирование в `build/measure/`. [Что именно сравнивается](examples/README_ru.md). Примеры не прошивают контроллер.

Размеры и такты в примерах относятся к указанным сборкам. Для оценки на другом контроллере воспользуйтесь методикой. [Методика замеров](docs/measurement_ru.md)

## Как подключить примеры к своему репозиторию

Начните с чистой рабочей копии своего Git-репозитория и выберите свободный путь для справочника. Из корня репозитория выполните первую команду один раз, а вторую используйте для получения обновлений.

```sh
git subtree add --prefix third_party/AVR-Cookbook https://github.com/Witali/AVR-Cookbook.git main --squash
git subtree pull --prefix third_party/AVR-Cookbook https://github.com/Witali/AVR-Cookbook.git main --squash
```

Примеры и справочник будут храниться в вашем репозитории. Чтобы повторить замеры, запустите из его корня `python3 third_party/AVR-Cookbook/examples/measure.py`. Для обновлений используйте тот же путь и параметр `--squash`. [Справка по Git subtree](https://github.com/git/git/blob/master/contrib/subtree/git-subtree.adoc)

Чтобы поделиться улучшением, создайте форк AVR-Cookbook, внесите правку в `examples/` и откройте pull request. Укажите целевой AVR, что изменилось и как вы это проверили. Если изменились описанное поведение или замеры, обновите документацию на обоих языках.
